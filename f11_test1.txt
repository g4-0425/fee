3. What do you know about flex layout?
-A Flex Layout is a CSS layout model that makes it easy to arrange, align,
  and distribute space among items inside a container.
- It is ideal when you want items in one dimension—either in a row or a column.
- Main concepts - flex direction 
                - justify-content
                - align-items

4.What is the need of Grid Layout?
- A Grid Layout is needed when you want to arrange elements in both rows and columns.
 While Flexbox is designed for one-dimensional layouts (either a row or a column), CSS Grid is designed for two-dimensional layouts.
 - Advantage-
- Organizes items in rows and columns
-Easier complex layouts
- Responsive design
